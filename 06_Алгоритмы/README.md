# Пузырьковая сортировка (Bubble Sort)

Пузырьковая сортировка - это простеший алгоритм сортировки, который сравнивает соседние элементы и меняет их местами, если они стоят в неправильном порядке

---

## Как это работает

1. Проходим по списку от начала до конца
2. Сравниваем каждый элемент с его соседом справа
3. Если левый больше правого - меняем их местами
4. Повторяем проходы, пока список не станет отсортированным

С каждым проходом самый большой элемент "всплывает" в конец списка

---

## Когда использовать

- Для обучения
- Для маленьких списков (до 100 элементов)
- Когда важда простота кода, а не скорость

---

## Когда не использовать

- Для больших списков - слишком медленно
- Когда важна производительность

---

# Быстрая сортировка (Quick Sort)

Быстрая сортировка — это один из самых эффективных алгоритмов сортировки.
Он работает по принципу "разделяй и властвуй": выбирает опорный элемент
(pivot), разделяет список на две части (меньше и больше pivot) и
рекурсивно сортирует каждую часть

---

## Как это работает

1. Выбираем опорный элемент (pivot)
2. Разделяем список на три части:
   - элементы меньше pivot
   - элементы равные pivot
   - элементы больше pivot
3. Рекурсивно сортируем левую и правую части
4. Соединяем результаты

---

## Аналогия

Представь, что ты разбираешь колоду карт. Ты берёшь одну карту (pivot)
и раскладываешь остальные на две стопки: меньше и больше. Потом делаешь
то же самое с каждой стопкой, пока все карты не будут отсортированы

---

## Два подхода

### 1. С созданием новых списков (проще для понимания)
```
def quick_sort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quick_sort(left) + middle + quick_sort(right)
```
Плюс: код короткий и понятный
Минус: создаёт много новых списков, тратит память

### 2. In-place (эффективнее, но сложнее)
```
def quick_sort_in_place(arr, low = 0, high = None):
    if high is None:
        high = len(arr) - 1
    if low < high:
        pivot_index = partition(arr, low, high)
        quick_sort_in_place(arr, low, pivot_index - 1)
        quick_sort_in_place(arr, pivot_index + 1, high)
```
Плюс: не тратит память на новые списки.
Минус: сложнее для понимания.

---

## Когда использовать

- Для больших списков (1000+ элементов)
- Когда важна скорость
- Когда память ограничена (in-place версия)

---

## Когда НЕ использовать

- Когда список уже отсортирован
- Когда важна стабильность сортировки (Quick Sort нестабилен)
