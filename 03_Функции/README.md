# Определение функций

Функция - блок кода, который можно вызвать по имени

# Синтаксис
```
def имя_функции(параметры: тип) -> тип_возврата:
    """Документация"""
    Тело функции
    return результат
```

# Аннотации типов (Type Hints)

Указывают, какой тип данных ожидается и что возвращается

- -> None - Функция ничего не возвращает
- -> int - Возвращает целое число
- -> str - Возвращает строку
- -> float | None - Возвращает число или None
- name: str - Параметр name - строка
- a: int, b: int - Оба параметра - целые число

# Docstring
Документация функции в тройных кавычках
Хороший тон - указывать, что делает функция, какие у нее параметры и что она возвращает

# Что такое `if __name__ == "__main__"`
Это конструкция, которая позволяет зпускать код только при прямом выполнении файла

```
if __name__ == "__main__": 
    say_hello()
```

Если файл импортирован как модуль - этот код не выполняется

# Правила имён
- Название функции должно отражать действие: get_user(), calculate_total()
- Использовать нижнее подчёркивание для разделения слов: my_function()

# Аргументы функций
Функции могут принимать данные через аргументы. В Python есть несколько способов передать аругменты, и каждый из них решает свою задачу

# Основные способы передачи аргументов
- Позиционные - передаются по порядку
- Именованные - указывается имя параметра
- Значение по умолчанию - если не передано, то используется значение по умолчанию
- *args - любое количество позиционных аргументов
- **kwargs - любое количество именованных аргументов

# *args - произвольное количество позиционных аргументов
Собирает все переданные позиционные аргументы в кортеж

```
def sum_all(*args):
    return sum(args)

sum_all(1, 2, 3)    # 6
```

# **kwargs - произвольное количество именованных аргументов
Собирает все переданные именованные аргументы в словарь

```
def print_data(**kwargs):
    for key, value in kwargs.items():
        print(f"{key}: {value}")

print_data(name = 'Toothless', age = 20)
```

# isinstance() - проверка типа объекта
Используется внутри функций, чтобы определить, как обработать переданные данные

```
isinstance(5, int)              # True
isinstance([1, 2], list)        # True
```

# Где это пригодится
- *args - для функций, которые работают с произвольным количеством чисел, строк или объектов
- **kwargs - для функций, которые принимают настройки, конфигурации или параметры
- isinstance() - для безопасной обработки данных, когда тип заранее неизвестен

# Области видимости переменных
Переменные в Python живут в разных "пространствах" - областях видимости. Понимание этих правил помогает избегать ошибок и писать предсказуемый код

---

# Глобальная область видимости - global scope
Переменная, объявленная вне всех функций, она доступна везде

```
x = 10      # глобальная

def func():
    print(x) # можно прочитать
```

# Локлаьная область видимости - local scope
Переменная, объявленная внутри функции, видна только внутри неё

```
def func():
    y = 5       # локальная
    print(y)

print(y) # Ошибка
```

# Глобальные переменные внутри функций
- Если просто читаешь глобальную переменную - `global` не нужен
- Если ты хочешь её изменить - нужно объявить `global name_var`

# nonlocal - для вложенных функций
Если внутри одной функции определена другая, и ты хочешь изменить переменную внешней функции - используй `nonlocal`

# Затенение
Если параметр функции или локальная переменная имеет то же имя, что и глобальная - она **затеняет** глобальную внутри функции


# Лямбда-функции

Лямбда (анонимная функция) - это функция без имени, которая определяется в одну строку

# Синтаксис

```
lambda параметры: выражение
```

# Особенности
- Лямбда - это выражение, а не блок кода
- Внутри не может быть циклов, условий (кроме тернарного) или return
- Результат возвращается автоматически
- Часто используется вместе с map(), filter(), sorted()

# Где применяются лямбды
- map() - рименяет функцию к каждому элементу
- filter() - оставляет элементы, прошедшие проверку
- sorted() - сортирует по ключу

# Когда не использовать лямбду
- Если логика занимает больше одной строки
- Если функция будет переиспользоваться в разных местах
- Если нужно больше одного выражения

# Рекурсия

Рекурсия - это когда функция вызывает саму себя

# Структура рекурсивной функции

```
def recursive(n):
    if условие_выхода:
        return значение
    return recursive(n - 1)
```

# Плюсы и минусы
Плюсы:
- Код короче и чище
- Удобно для вложенных структур
- Естественно для некоторых задач

Минусы:
- Может быть медленнее циклов
- Ограничение глубы вызовов
- Тяжело отлаживать

# Когда использовать рекурсию
- Задача естественно разбивается на подзадачи
- Работаешь с деревьями, папками, вложенными списками
- Глубина вложенности заранее неизвестна
- Код с рекурсией короче и понятнее, чем с циклами

# Когда не стоит использовать рекурсию
- Задача решается простым циклом
- Глубина рекурсии может быть очень большой (можно исправить)
- Тебе важна производительность (можно исправить)
- Код становится сложнее для понимания
