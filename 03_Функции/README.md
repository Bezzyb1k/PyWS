# Определение функций

Функция - блок кода, который можно вызвать по имени

# Синтаксис

def имя_функции(параметры: тип) -> тип_возврата:
    """Документация"""
    Тело функции
    return результат

# Аннотации типов (Type Hints)

Указывают, какой тип данных ожидается и что возвращается

- -> None - Функция ничего не возвращает
- -> int - Возвращает целое число
- -> str - Возвращает строку
- -> float | None - Возвращает число или None
- name: str - Параметр name - строка
- a: int, b: int - Оба параметра - целые число

# Docstring
Документация функции в тройных кавычках
Хороший тон - указывать, что делает функция, какие у нее параметры и что она возвращает

# Правила имён
- Название функции должно отражать действие: get_user(), calculate_total()
- Использовать нижнее подчёркивание для разделения слов: my_function()
