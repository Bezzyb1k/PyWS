# Определение функций

Функция - блок кода, который можно вызвать по имени

# Синтаксис
```
def имя_функции(параметры: тип) -> тип_возврата:
    """Документация"""
    Тело функции
    return результат
```

# Аннотации типов (Type Hints)

Указывают, какой тип данных ожидается и что возвращается

- -> None - Функция ничего не возвращает
- -> int - Возвращает целое число
- -> str - Возвращает строку
- -> float | None - Возвращает число или None
- name: str - Параметр name - строка
- a: int, b: int - Оба параметра - целые число

# Docstring
Документация функции в тройных кавычках
Хороший тон - указывать, что делает функция, какие у нее параметры и что она возвращает

# Что такое `if __name__ == "__main__"`
Это конструкция, которая позволяет зпускать код только при прямом выполнении файла

```
if __name__ == "__main__": 
    say_hello()
```

Если файл импортирован как модуль - этот код не выполняется

# Правила имён
- Название функции должно отражать действие: get_user(), calculate_total()
- Использовать нижнее подчёркивание для разделения слов: my_function()

# Аргументы функций
Функции могут принимать данные через аргументы. В Python есть несколько способов передать аругменты, и каждый из них решает свою задачу

# Основные способы передачи аргументов
- Позиционные - передаются по порядку
- Именованные - указывается имя параметра
- Значение по умолчанию - если не передано, то используется значение по умолчанию
- *args - любое количество позиционных аргументов
- **kwargs - любое количество именованных аргументов

# *args - произвольное количество позиционных аргументов
Собирает все переданные позиционные аргументы в кортеж

```
def sum_all(*args):
    return sum(args)

sum_all(1, 2, 3)    # 6
```

# **kwargs - произвольное количество именованных аргументов
Собирает все переданные именованные аргументы в словарь

```
def print_data(**kwargs):
    for key, value in kwargs.items():
        print(f"{key}: {value}")

print_data(name = 'Toothless', age = 20)
```

# isinstance() - проверка типа объекта
Используется внутри функций, чтобы определить, как обработать переданные данные

```
isinstance(5, int)              # True
isinstance([1, 2], list)        # True
```

# Где это пригодится
- *args - для функций, которые работают с произвольным количеством чисел, строк или объектов
- **kwargs - для функций, которые принимают настройки, конфигурации или параметры
- isinstance() - для безопасной обработки данных, когда тип заранее неизвестен
