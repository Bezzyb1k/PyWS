# Стек

Стек - это структура данных, работающая по принципу LIFO (Last In, First Out)
Последний добавленный элемент покидает стек первым

---

## Важное уточнение

Мы создаем стек с нуля через класс "Stack"
Это сделано для понимания внутреннего устройста
В Python нет отдельного встроенного типа "Стек", но список list уже поддерживает похожие операции: `append()` для добавления в конец и `pop()` для удаления с конца

Наша реализация нужна, чтобы
- скрыть внутренние детали (инкапсуляция)
- отставить только нужные методы
- чётко показать логику работы стека

---

## Аналогия

Стек похож на стопку тарелок
Ты кладешь новую тарелку сверху и берешь тоже сверху
Середина или низ стопки недопступы, пока не убраны верхние тарелки

---

## Методы

| Метод | Назначение |
| ----- | ---------- |
| push(item) | Добавляет элемент на вершину стека |
| pop() | Убирает и возвращает верхний элемент |
| peek() | Показывает верхний элемент без удаления |
| is_empty() | Проверяет, пуст ли стек |
| size() | Возвращает количество элементов |

---

## Где применяется

- Отмена действий - каждое действие пользователя сохраняется в стек. Когда пользователь нажимает "оменить", последнее действие извлекается и откатывается
- История браузера - каждая новая страница, которую ты открываешь, добавляется в стек. Кнопка "назад" берет последнюю страницу и удаляет её
- Вызовы функций - когда программа вызывает функцию, Python сохраняет текущее сосотяние в стеке. Когда функция завершается - состояние овсстанавливается
- Проверка парности скобок в коде - компиляторы и редакторы кода проверяют, правильно ли рассталвены скобки в выражении
- Восстановление системы после сбоя - некоторые системы сохраняют все действия в стеке. При сбое можно "перемотать" систему назад, повторяя действия из стека (пример NixOS)

---

## Когда стек не подходит

- Если нужен доступ к элементам по индексу
- Если нужен порядок FIFO (первйы пришел - первый ушел) - для этого есть очередь


# Очередь

Очередь - это структура данных, работающая по принципу FIFO (First In, First Out)
Первый добавленный элемент покидает очередь первым

---

## Аналогия

Очередь похожа на очередь в магазине. Первый, кто встал, первым и уходит
Ты не можешь подойти к кассе из середины очереди - только с начала

---

## Методы

| Метод | Назначение |
| ----- | ---------- |
| enqueque(item) | Добавляет элемент в конец очереди |
| dequeue() | Убирает и возвращает первый элемент |
| peek() | Показывает первый элемент без удаления |
| is_empty() | Проверяет, пуста ли очередь |
| size() | Возвращает количество элементов |

---

## Где применяется

### 1. Обработк азадач в порядке поступления

**Что происходит:** Задачи приходят в систему и обрабатываются в том порядке, в котором поступили

**Почему очередь:** Если задачи обрабатывать в порядке поступления, никто не останется без внимания. Очередь гарантирует честный порядок

### 2. Буферизация данных (потоковая передача)

**Что происходит:** Данные приходят быстрее, чем их можно обработать. Очередь временно хранит их, пока обработчик не освободится

**Почему очередь:** Данные должны обрабатываться в том порядке, в котором пришли. Если использовать стек, порядок нарушится

---

### 3. Обход графа в ширину (BFS)

**Что происходит:** BFS обходит граф слоями: сначала все соседи стартовой вершины, потом соседи соседей и так далее

**Почему очередь:** BFS должен обрабатывать вершины в порядке их обнаружения. Очередь гарантирует, что вершины одного уровня обрабатываются раньше, чем вершины следующего

---

### 4. Планирование задач

**Что происходит:** Операционная система распределяет время процессора между задачами

**Почему очередь:** Задачи должны получать время в порядке поступления. Очередь гарантирует, что ни одна задача не будет забыта

---

### 5. Асинхронная обработка (очереди сообщений)

**Что происходит:** Сообщения от разных источников собираются в очередь и обрабатываются по одному

**Почему очередь:** Сообщения должны обрабатываться в порядке поступления. Очередь гарантирует, что ни одно сообщение не потеряется

---

## Отличие от стека

| Стек | Очередь |
| ---- | ------- |
| LIFO (Последний пришел - Первый ушел) | FIFO (Первый пришел - Первый ушел) |
| Добавление и удаление с одного конца | Добавление с одного конца, удаление с другого |

---

## Когда очередь не подходит

- если нужен доступ к элементам по индексу
- если нужен порядок LIFO
