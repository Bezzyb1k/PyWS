# Стек

Стек - это структура данных, работающая по принципу LIFO (Last In, First Out)
Последний добавленный элемент покидает стек первым

---

## Важное уточнение

Мы создаем стек с нуля через класс "Stack"
Это сделано для понимания внутреннего устройста
В Python нет отдельного встроенного типа "Стек", но список list уже поддерживает похожие операции: `append()` для добавления в конец и `pop()` для удаления с конца

Наша реализация нужна, чтобы
- скрыть внутренние детали (инкапсуляция)
- отставить только нужные методы
- чётко показать логику работы стека

---

## Аналогия

Стек похож на стопку тарелок
Ты кладешь новую тарелку сверху и берешь тоже сверху
Середина или низ стопки недопступы, пока не убраны верхние тарелки

---

## Методы

| Метод | Назначение |
| ----- | ---------- |
| push(item) | Добавляет элемент на вершину стека |
| pop() | Убирает и возвращает верхний элемент |
| peek() | Показывает верхний элемент без удаления |
| is_empty() | Проверяет, пуст ли стек |
| size() | Возвращает количество элементов |

---

## Где применяется

- Отмена действий - каждое действие пользователя сохраняется в стек. Когда пользователь нажимает "оменить", последнее действие извлекается и откатывается
- История браузера - каждая новая страница, которую ты открываешь, добавляется в стек. Кнопка "назад" берет последнюю страницу и удаляет её
- Вызовы функций - когда программа вызывает функцию, Python сохраняет текущее сосотяние в стеке. Когда функция завершается - состояние овсстанавливается
- Проверка парности скобок в коде - компиляторы и редакторы кода проверяют, правильно ли рассталвены скобки в выражении
- Восстановление системы после сбоя - некоторые системы сохраняют все действия в стеке. При сбое можно "перемотать" систему назад, повторяя действия из стека (пример NixOS)

---

## Когда стек не подходит

- Если нужен доступ к элементам по индексу
- Если нужен порядок FIFO (первйы пришел - первый ушел) - для этого есть очередь
