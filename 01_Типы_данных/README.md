# Числа в Python

В Python есть два основных числовых типа
- int (целые)
- float (вещественные)

# Основные операции
- '+' - сложение
- '-' - вычитание
- '*' - умножение
- '/' - деление (всегда возвращает float)
- '//' - деление без остатка (всегда возвращает int)
- '%' - остаток от деления
- '**' - возведение в степень

# Порядок выполнения операций
Как и в математике приоритет выполнения является таким:
скобки --> степень --> умножение/деление --> сложение/вычитание

# Сравнение чисел
- '==' - равно
- '!=' - не равно
- '>' - больше
- '<' - меньше
- '>=' - больше или равно
- '<=' - меньше или равно

# Встроенные функции
- abs() - модуль числа
- round() - округление числ
- pow() - возведение в степень


# Строки в Python

Строка ('str') - неизменяемый упорядоченный набор символов

# Способы создания
- Одинарные кавычки 'текст'
- Двойные кавычки "текст"
- Тройные кавычки """текст"""

# Основные операции
- '+' - Объединяет две строки
- '*' - Повторяет строку N раз
- 'in' - Возвращает True, если подстрока есть
- 'not in' - Возвращается True, если подстроки нет
- '[]' - Доступ к символу по индексу (начало с 0)
- '[:]' - Срезы строки, извлечение части строки

# Индексация
- Прямая: [0] - первый символ, [2] - третий символ
- Обратная: [-1] - последний символ, [-2] - предпоследний символ

# Срезы (синтаксис)
стоп:старт:шаг
- 'старт' - с какого индекса начинать (включительно)
- 'стоп' - на каком индексе остановиться (не включительно)
- 'шаг' - с каким шагом

# Основные методы
- .upper() - Все символы в верхний регистр
- .lower() - Все символы в нижний регистр
- .capitalize() - Первый символ - заглавный, остальные - строчные
- .strip() - Удаляем пробелы и переносы в начале и в конце
- .replace() - Заменяет подстроку
- .split() - Разбивает строку по разделителю на список
- .join() - Объединяет элементы списка в строку через разделитель
- .find() - Возвращает индекс первого вхождения подстроки
- .count() - Количество вхождений подстроки
- .isalpha() - Состоит ли строка только из букв
- .isdigit() - Состоит ли строка только из цифр
- .isalnum() - Состоит ли строка только из букв и цифр


# Списки в Python

Список ('list') - изменяемый упорядоченный тип данных, который может содержать элементы разных типов

# Создание
- [] - пустой список
- [1, 2, 3.14], ['a', 'b', 'c'], [True, False] - числовой, строчный, булевый список
- [1, True, 'z'] - смешанный список

# Основные характеристики
- **Изменяемость** - можно добавлять, удалять, заменять элементы
- **Упорядоченность** - элементы имеют порядок и доступны по индексу
- **Гетерогенность** - могут хранить элементы разных типов

# Индексация
- [0] - первый элемент
- [-1] - последний элемент
- [0:3] - срез, не включаю элемент с индексом 3

# Основные операции
- '+' - Объединение списков
- '*' - Повторение списка N раз
- 'in' - Проверка вхождения элемента
- 'not in' - Проверка отсутствия элемента

# Основные методы
- .append() - Добавления элемента в конец
- .insert() - Добавление элемента на указанную позицию
- .pop() - Удаляет и возвращает элемент по индексу (по умолчанию последний)
- .remove() - Удаляет первое вхождение элемента
- .clear() - Очищает список
- .index() - Возвращает индекс первого вхождения элемента
- .count() - Подсчет количество вхождений элементов
- .sort() - Сортирует список
- .reverse() - Разворачивает список
- .copy() - Создает копию списка


# Кортежи в Python

Кортеж ('tuple') - _неизменяемая_ упорядоченная коллекция, которая может содержать элементы разных типов

## Создание
- (), tuple() - Пустой кортеж
- (1, 2, 3) - Классический способ
-  1, 2, 3 - Без скобок
- (1,) - Один элементы, **Запятая обязательна**

## Основные характеристики
- **Неизменяемость** - нельзя добавлять, удалять или изменять элементы после создания
- **Упорядоченность** - элементы имеют порядок и доступны по индексу
- **Гетерогенность** - могут хранить элементы разных типов
- **Хешируемость** - могут использоваться как ключи в словарях (в отличие от списков)

## Индексация и срезы
Работают так же, как у списков:
- [0] - первый элемент
- [-1] - последний элемент
- [0:3] - срез (не включает индекс 3)
- [::-1] - разворот кортежа

## Основные операции
- '+' - Объединение
- '*' - Повторение
- in - Проверка вхождения
- not in - Проверка отсутсвия

## Распаковка
Присваивание элементов кортежа отдельным переменным. Количество перменных должно совпадать с количеством элементов
notes = ('Do', 'Re', 'Mi')
do, re, mi = notes  # do = 'Do', re = 'Re', mi = 'Mi'

## Вложенные кортежи
Кортеж может содержать другие кортежи (или списки). Доступ к вложенным элементам - по цепочкам индексов
box = ('firstbox', (1, 2))
box[1][0] # 1

## Встроенные функции
- len() - Длина кортежа
- max() - Максимальный элемент (для чисел)
- min() - Минимальный элемент (для чисел)
- sum() - Сумма элементов (для чисел)
- sorted() - Возвращает **отсортированный список** (кортеж при этом не меняется)

## Конвертация
- list(tuple) - превращает кортеж в список
- tuple(list) - превращает список в кортеж

## Важные нюансы
1. Кортежи неизменяемы, но если внутри кортежа лежит **список**, то содержимое этого списка можно изменять
2. Кортеж из одного элемента обязательно пишется с запятой: (5,) - это кортеж, а (5) - это число


# Словари в Python

Словарь ('dict') - изменяемая неупорядоченная коллекция, которая хранит пары **ключ: значение**

# Создание
- dict(), {} - пустой словарь
- {"name": "Toothless", "age": 20} - словарь с данными
- dict(name = "Toothless", age = 20)

# Основные характеристики
- **Изменяемость** -  можно добавлять, удалять и изменять пары
- **Неупорядоченность** - элементы не имеют порядка 
- **Уникальность ключей** - каждый ключ может встречаться только один раз
- **Хешируемость ключей** - ключами могут быть только неизменяемые типы

# Основные операции
- dict[key] = value - добавление или изменение значения по ключу
- dict[key] - получение значения по ключу
- dict.get(key) - получение значения по ключу (если нет - возвращает None)
- dict.get(key, default) - получение значения по ключу (если нет - возвращает default)
- del dict[key] - удаление пары по ключу
- key in dict - проверка наличия ключа в словаре
- dict.keys() - возвращает все ключи
- dict.values() - возвращает все значения
- dict.items() - возвращает пары ключ:значения
- dict.pop(key) - удаляет и возвращает значение по ключу
- dict.popitems() - удаляет и возвращает последнюю добавленную пару
- dict.update(other_dict) - объединяет словари
- dict.clear() - очищает словарь
- dict.copy() - создает копию словаря

# Когда использовать словари
- Хранение данных с быстрым доступом по индентификатору (пользователи по ID)
- Конфигурация и настройки (config['theme'] = 'dark')
- Создание кэша
- Хранение данных в JSON - подобном формате

# Важные нюансы
1. Если обратиться к несуществующему ключу через dict[key] - будет ошибка. Лучше использовать dict.get()
2. Ключи должны быть неизменяемыми. Списки и словари не подходят
3. Словари передаются по ссылке - при копировании через '=' создается ссылка. Лучше использовать dict.copy() для создания отдельной копии


# Множество в Python

Множество ('set') - изменяемая неупорядоченная коллекция **уникальны** элементов

# Основные характеристики
- **Неупорядоченность** - элементы не имеют индекса (нельзя обратиться по индексу)
- **Уникальность** - все элементы внутри множества уникальны
- **Изменяемость** - можно добавлять и удалять элементы
- **Хешируемость элементов** - внутри множества могут быть только неизменяемые типы. Списки и словари нельзя добавить во множество

# Основные операции
- add(x) - добавляет элемент (если он уже есть - ничего не добавит)
- remove(x) - удаляет элемент, если нету выдаст ошибку KeyError
- discraft(х) - удаляет элемент, если он есть, если нету ничего не сделает
- pop() - удаляет и возвращает произвольный элемент
- clear() - очищает множество
- len() - количество элементов
- x in set - проверка наличия элемента
- set1 | set2 - объединение множеств
- set1 & set2 - пересечение множеств
- set1 - set2 - разность множеств (элементы из первого, которых нет во втором)
- set1 ^ set2 - симметричная разность (элементы, которые есть только в одном из множеств)

# Когда использовать множество
- Удаление дубликатов из списка
- Быстрая поверка наличия элемента
- Поиск общих элементов между двумя коллекциями
- Подсчёт уникальных слов в тексте

# Важные нюансы
1. Множества **не упорядоченные** - порядок элементов не гарантируется и может  меняться
2. Пустое множество создается через set(), а не через {}
3. Элементы множества должны быть **хешируемыми**
4. Множества работают очень быстро - проверка in занимает почти мгновение для очень большого количества элементов


# Булевые значения и логические операции

bool - логический тип данных, который может принимать два значения True (истина) и False (ложь)

# Создание 
- True - константа истины
- False - константа лжи
- Результаты сравнение 2 > 1 -> True
- Результаты логический операций True and False -> False

# Логичнские операторы
- and - И (оба условия должны быть истинными) True and True -> True
- or - ИЛИ (хотя бы одно условие истинно) True or False -> True
- not - НЕ (меняет значение на противоположное) not True -> False

# Приоритет операторов (от высшего к низшему)
1. not
2. and
3. or

# Что считается False
- None
- False
- Числовой ноль 0, 0.0, 0j
- Пустые коллекции "", [], (), {}, set()

# Что считается True
- Любое непустое значение
- Любое ненулевое число
- Любая непустая коллекция
- True

# Когда использовать
- Ветвления if / elif / else
- Циклы while
- Проверка ввода
- Валидация данных
- Флаги и состояния

# Важные нюансы
1. bool является подтипом int, True == 1, False == 0
2. Сравнение == и is - разные вещи. == сравнивает значения, is сравнивает индентичность объектов

# Преобразование типов в Python

Преобразование типов (или приведение) - это процесс явного или неявного изменения типа данных

# Виды преобразования
1. **Неявное (автоматическое)** - Python сам меняет тип, если это безопасно
2. **Явное (ручное)** - ты указываешь, во что превратить значение

# Встроенные функции для преобразования
- int() - превращение в целое число
- float() - превращение в число с плавающей точкой
- str() - превращение в строку
- bool() - превращение в логическое значение
- list() - превращение в список
- tuple() - превращение в кортеж
- set() - превращение в множество
- dict() - превращение в словарь

# Важные нюансы
1. Не все можно преобразовать: int("abc") - вызовет ошибку ValueError
2. При преобразовании числа с плавающей точкой в целое дробная часть **отбрасывается**
