# Объектно-ориентированное программирование (ОПП)

ООП - это способ организации кода, при котором ты думаешь о **сущностях** (объектах), а не о последовательности действий 

---

## Основные понятия
- Класс - класс описывает, как устроены все объекты этого типа. Он определяет, какие у них будут атрибуты и методы. Сам по себе класс не хранит конкретные данные - он только описывает структуру
- Экземпляр (Объект) - это реальная сущность, у которой есть свои собственные атрибуты (значения), но поведение (методы) у всех экземпляров одно и тоже. Можно создать сколько угодно экземпляров одного класса
- Атрибут - это данные, которые характеризуют конкретныз объект. Например, у игрока это name, health, level. Каждый экземпляр хранит свои значения атрибутов
- Метод - это действие, которое объект может выполнять. Метод работает с атрибутами объекта через self. Например, take_damage() изменяет health конкретного игрока
- Конструктор (`__init__`) - он задает начальные значения атрибутов. Вызывается атоматически, когда ты пишешь Player("Toothless"). Без конструктора пришлось бы настраивать объект вручную после создания
- self - это указатель на тот экземпляр, с которым работает метод. Без self метод не знал бы, чьи атрибуты менять. Когда ты пишешь player1.take_damage(), Python авотматически передает в метод player1 как self

## Сравнение: Функции и Классы
| Функции | Классы |
|---------|--------|
| Данные и логика разделены | Данные и логика объекдинены в объекте |
| Нужно передавать все параметры каждый раз | Методы автоматически имеют доступ к своим данным |
| Сложно управлять состоянием | Состояние хранится внутри объекта |
| Дублирование кода | Код переиспользуется через наследование |
| Трудно расширять | Легко добавлять новые типы объектов |
