# Объектно-ориентированное программирование (ОПП)

ООП - это способ организации кода, при котором ты думаешь о **сущностях** (объектах), а не о последовательности действий 

---

## Основные понятия
- Класс - класс описывает, как устроены все объекты этого типа. Он определяет, какие у них будут атрибуты и методы. Сам по себе класс не хранит конкретные данные - он только описывает структуру
- Экземпляр (Объект) - это реальная сущность, у которой есть свои собственные атрибуты (значения), но поведение (методы) у всех экземпляров одно и тоже. Можно создать сколько угодно экземпляров одного класса
- Атрибут - это данные, которые характеризуют конкретныз объект. Например, у игрока это name, health, level. Каждый экземпляр хранит свои значения атрибутов
- Метод - это действие, которое объект может выполнять. Метод работает с атрибутами объекта через self. Например, take_damage() изменяет health конкретного игрока
- Конструктор (`__init__`) - он задает начальные значения атрибутов. Вызывается атоматически, когда ты пишешь Player("Toothless"). Без конструктора пришлось бы настраивать объект вручную после создания
- self - это указатель на тот экземпляр, с которым работает метод. Без self метод не знал бы, чьи атрибуты менять. Когда ты пишешь player1.take_damage(), Python авотматически передает в метод player1 как self

## Сравнение: Функции и Классы
| Функции | Классы |
|---------|--------|
| Данные и логика разделены | Данные и логика объекдинены в объекте |
| Нужно передавать все параметры каждый раз | Методы автоматически имеют доступ к своим данным |
| Сложно управлять состоянием | Состояние хранится внутри объекта |
| Дублирование кода | Код переиспользуется через наследование |
| Трудно расширять | Легко добавлять новые типы объектов |


# Наследование

Наследование - это механизм, который позволяет создать новый класс на основе существующего. Дочерний класс получает все атрибуты и методы родителя и может добавлять свои или изменять родительские

## Синтаксис

```
class Родитель:
    def __init__(self, ...):
        ...


class Дочерний(Родитель):
    def __init___(self, ...):
        super().__init__(...) # вызов конструктора родителя
        self.новый_атрибут = ...
```

## Что такое `super()` и зачем он нужен
`super()` - это ссылка на родительский класс. Она нужна, чтобы:
- Вызывать конструктор родителя и не дублировать код
- Использовать методы родителя, если нужно дополнить их, а не переопределить полностью
Без `super()` пришлось бы заново писать `self.name = name` и т.д.


# Инкапсуляция
Инкапсуляция - это механизм, который скрывает внутренее состояние объекта и предоставляет доступ к нему только через специальные методы (геттер и сеттеры)

## Как работает инкапсуляция в Python

| Синтаксис | Уровень доступа | Описание |
| --------- | --------------- | -------- |
| 'self.name' | Публичный | Доступен везде |
| 'self._name' | Защищенный | По соглашению - не трогать снаружи |
| 'self.__name' | Приватный | Доступен только внутри класса |


# Полиморфизм

Полиморфизм - это когда разные объекты умеют делать одно и то же, но по-своему

---

## Для чего нужен полиморфизм
1. **Гибкость кода** - можно добавлять новые типы башен, врагов, предметов, не переписывая старую логику
2. **Один интерфейс** - ты работаешь с любым объектом через знакомый метод, не думая о его типе
3. **Чистота кода** - не нужно писать длинные цепочки
4. **Расширяемость** - новая башня просто подключается к системе, если у нее есть нужные методы
5. **Универскальные функции** - можно написать одну функцию, которая работает с любым наследником базового класса


# Магические методы

Магические методы - это специальные методы с двойным подчёркиванием, которые определяют поведение объекта

---

## Для чего нужны

- Позволяет объектам работать со встроенными операторами
- Делают код более естественным и читаемым
- Дают возможность управлять тем, как объект отображается, сравнивается, складывается и т.д.

---

## Основные магические методы

| Метод | Назначение | Пример вызова |
| ----- | ---------- | ------------- |
| `__init__` | Конструктор | `obj = MyClass()` |
| `__str__` | Строковое представление (для пользователя) | `print(obj)` |
| `__repr__` | Строковое представление (для отладки) | `repr(obj)` |
| `__add__` | Сложение | `obj1 + obj2` |
| `__sub__` | Вычитание | `obj1 - obj2` |
| `__mul__` | Умножение | `obj1 * 2` |
| `__eq__` | Сравнение на равенство | `obj1 == obj2` |
| `__len__` | Длина объекта | `len(obj)` |
| `__call__` | Вызов объекта как функции | `obj()` |

---

## Что дают магические методы
- Объекты становятся как настоящие - их можно складывать, сравнивать, вызывать
- Код становится короче и понятнее
- Можно адаптировать поведение объктов под любые задачи


# Статические методы и методы класса

## Статические методы (`@staticmethod`)

- Принадлежат классу, но **не имеют доступа** к атрибутам класса или объекта
- Используются как утилиты - вспомогательные функции, связанные по смыслу с классом
- Не принимают `self` или `cls`

```
class Player:
    @staticmethod
    def is_valid_name(name: str) -> bool:
        return len(name) >= 2 and name.isalnum()
    
Player.is_valid_name("Toothless") # True
```

---

## Методы класса (`@classmethod`)

- Принадлежит классу и **имеет доступ** к атрибутам класса через `cls`
- Используеются как **фабрики** - альтернативные способы создания объектов

```
class Player:
    max_health = 100

    @classmethod
    def create_default(cls, name: str) -> "Player":
        if not cls.is_valid_name(name):
            name = "Default"
        return cls(name)

player = Player.create_default("Toothless")
```

В Python `cls` - это стандартное имя для первого аргумента в методах класса, которое ссылается на сам класс, а не на его отдельный объект

**Главное о `cls`**
- Означает класс: Сокращение от английского слова class
- Аналог `self`: Похож на `self`, но `self` указывает на конкретный экземпляр (объект), а `cls` - на чертёж этого объекта (сам класс)

**Зачем нужен**
- Создание объектов: Позволяет создавать новые экземпляры класса прямо внутри его методов (например, в альтернативных конструкторах)
- Доступ к данным классса: Даёт возможность читать и менять общие переменные (атрибуты) класса

---

## Отличия

| Метод | Принимает | Может менять класс | Может менять объект | Пример |
| ----- | --------- | ------------------ | ------------------- | ------ |
| Обычный | `self` | Нет | Да | `player.take_damage()` |
| `@classmethod` | `cls` | Да | Нет | `Player.creeate_default()` |
| `@staticmethod` | Ничего | Нет | Нет | `Player.is_valid_name()` |

---

## Когда использовать

| Ситуация | Решение |
| -------- | ------- |
| Нужна вспомогательная функция, связанная с классом | `@staticmethod`  |
| Нужно создать объект с настройками по умолчанию | `@classmethod` |
| Нужно создать объект из разных форматов данных | `@classmethod` |
| Нужно изменить глобальные настройки класса | `@classmethod` |
