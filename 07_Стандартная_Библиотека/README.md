# Модуль os

Модуль os — это встроенный инструмент Python для работы с файлами, папками и путями

---

## Что реально используется

| Функция | Что делает |
|---------|------------|
| os.getcwd() | Текущая директория |
| os.listdir() | Список файлов в папке |
| os.path.exists() | Проверка существования |
| os.path.isfile() | Это файл? |
| os.path.isdir() | Это папка? |
| os.mkdir() | Создать папку |
| os.rmdir() | Удалить пустую папку |
| os.path.join() | Соединить пути |
| os.path.dirname() | Папка из пути |
| os.path.basename() | Файл из пути |
| os.path.getsize() | Размер файла |

---

## Где применяется

- Загрузка сохранений в игре
- Чтение конфигов
- Сортировка файлов
- Сохранение логов

---

# Модуль sys

Модуль sys — это встроенный инструмент Python для работы с системой
и интерпретатором. Он даёт доступ к версии Python, аргументам командной строки, пути поиска модулей и выходу из программы

---

## Что реально используется

| Функция / атрибут | Что делает |
|-------------------|------------|
| sys.version | Версия Python |
| sys.version_info | Версия в виде кортежа |
| sys.platform | Название платформы (linux, win32) |
| sys.argv | Аргументы командной строки |
| sys.path | Пути поиска модулей |
| sys.exit() | Выход из программы |
| sys.getsizeof() | Размер объекта в байтах |
| sys.getrecursionlimit() | Предел рекурсии |
| sys.setrecursionlimit() | Установить предел рекурсии |
| sys.stdout | Стандартный вывод |
| sys.stderr | Стандартный вывод ошибок |

---


## Где применяется

- Проверка версии Python (совместимость)
- Чтение аргументов командной строки (утилиты)
- Выход из программы с кодом ошибки
- Управление путями поиска модулей
- Отладка (вывод в stderr)

---

## Важные нюансы

1. sys.argv[0] — это имя самого скрипта. Аргументы начинаются с sys.argv[1]
2. sys.exit(0) — успешный выход. sys.exit(1) — выход с ошибкой
3. sys.path можно изменять, чтобы добавить свои папки для импорта
4. sys.getsizeof() возвращает размер объекта в байтах (включая служебные данные)
5. Увеличение предела рекурсии может привести к переполнению стека

# Модули datetime и time

В Python есть два разных инструмента для работы со временем:

- datetime — для работы с датами и временем (год, месяц, день, час)
- time — для работы с системным временем (паузы, Unix время)

---

## datetime

| Класс / метод | Что делает |
|---------------|------------|
| datetime.now() | Текущая дата и время |
| date(год, месяц, день) | Создать дату |
| datetime.time(час, минута, секунда) | Создать время |
| datetime(год, месяц, день, час, минута) | Создать дату и время |
| strftime(формат) | Форматировать дату в строку |
| strptime(строка, формат) | Распарсить строку в дату |
| timedelta(days=, hours=, minutes=) | Разница во времени |

---

## Форматы strftime

| Код | Значение | Пример |
|-----|----------|--------|
| %d | День | 18 |
| %m | Месяц | 10 |
| %Y | Год | 2026 |
| %H | Час (24) | 14 |
| %M | Минута | 30 |
| %S | Секунда | 45 |
| %A | День недели | Sunday |
| %B | Месяц (название) | October |

---

## time

| Функция | Что делает |
|---------|------------|
| time.time() | Unix время (секунды с 1970) |
| time.sleep(сек) | Пауза на N секунд |
| time.ctime() | Unix время в читаемую строку |

---

## Разница между datetime и time

| datetime | time |
|----------|------|
| Работа с датами | Работа с системным временем |
| Год, месяц, день | Секунды с 1970 |
| Форматирование | Паузы, замеры |

---


## Где применяется

- Игры: таймеры, кулдауны, сохранения с датой
- Скрипты: логи с временем, паузы
- Боты: ежедневные напоминания

---

# Модуль json

Модуль json — это встроенный инструмент Python для работы с JSON-данными
JSON — это текстовый формат хранения данных, который выглядит как словари и списки в Python

---

## Что реально используется

| Функция | Что делает |
|---------|------------|
| json.dumps() | Python --> JSON-строка |
| json.loads() | JSON-строка --> Python |
| json.dump() | Python --> файл JSON |
| json.load() | Файл JSON --> Python |

---

## Разница между dumps/loads и dump/load

| Строки | Файлы |
|--------|-------|
| dumps() | dump() |
| loads() | load() |
| Работает со строками | Работает с файлами |

---

## Параметры dumps/dump

| Параметр | Что делает |
|----------|------------|
| ensure_ascii = False | Сохраняет русские буквы (не экранирует) |
| indent = 2 | Красивый вывод с отступами |
| sort_keys = True | Сортирует ключи по алфавиту |

---

## Где применяется

- Игры: сохранения, конфиги, настройки
- API: ответы серверов
- Веб: передача данных между клиентом и сервером
- Конфиги: настройки программ

---

## Важные нюансы

1. dumps() и loads() работают со строками
2. dump() и load() работают с файлами
3. Всегда указывай encoding="utf-8" при работе с файлами
4. ensure_ascii = False нужен, чтобы русские буквы не превращались в \uXXXX
5. JSON не поддерживает комментарии

---

# Модуль random

Модуль random — это встроенный инструмент Python для генерации случайных чисел и случайного выбора

---

## Что реально используется

| Функция | Что делает |
|---------|------------|
| random.random() | Случайное float от 0 до 1 |
| random.randint(a, b) | Случайное целое от a до b |
| random.randrange(start, stop, step) | Случайное целое с шагом |
| random.choice(seq) | Случайный элемент из последовательности |
| random.sample(seq, k) | k случайных элементов без повторов |
| random.choices(seq, k) | k случайных элементов с повторами |
| random.shuffle(seq) | Перемешать список на месте |
| random.uniform(a, b) | Случайное float от a до b |
| random.seed(n) | Зафиксировать генератор |

---


## Где применяется

- Игры: спавн врагов, выпадение лута, случайный урон
- Тесты: генерация случайных данных
- Пароли: генерация случайных строк
- Симуляции: случайные события

---

## Важные нюансы

1. random.randint(a, b) включает оба конца (a и b)
2. random.randrange(start, stop) не включает stop
3. random.choice() работает с любыми последовательностями
4. random.sample() не повторяет элементы
5. random.choices() может повторять элементы
6. random.seed() нужен для воспроизводимости (тесты, отладка)

---

# Модуль math

Модуль math — это встроенный инструмент Python для математических
вычислений. Он даёт доступ к константам, округлению, корням,
тригонометрии и логарифмам

---

## Что реально используется

| Функция | Что делает |
|---------|------------|
| math.pi | Число Пи (3.14159...) |
| math.e | Число e (2.71828...) |
| math.ceil(x) | Округление вверх |
| math.floor(x) | Округление вниз |
| math.trunc(x) | Отбрасывает дробную часть |
| math.sqrt(x) | Квадратный корень |
| math.pow(x, y) | x в степени y |
| math.dist(p1, p2) | Расстояние между точками |
| math.degrees(x) | Радианы -> градусы |
| math.radians(x) | Градусы -> радианы |
| math.sin(x) | Синус |
| math.cos(x) | Косинус |
| math.tan(x) | Тангенс |
| math.atan2(y, x) | Угол между точками |
| math.log(x) | Натуральный логарифм |
| math.log10(x) | Логарифм по основанию 10 |
| math.log2(x) | Логарифм по основанию 2 |

---


## Где применяется

- Игры: расстояние между объектами, углы, траектории
- Графика: повороты, масштабирование
- Алгоритмы: корни, логарифмы, степени
- Физика: расчёт скоростей, ускорений

---

## Важные нюансы

1. math.ceil() округляет вверх, math.floor() — вниз
2. math.trunc() просто отбрасывает дробную часть (не округляет)
3. math.dist() работает с кортежами или списками координат
4. math.atan2(y, x) возвращает угол в радианах от -pi до pi
5. math.sqrt() не работает с отрицательными числами (используй cmath)
