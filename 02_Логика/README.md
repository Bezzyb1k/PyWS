# Логика и управление потоком

Этот блок - про то, как программа принимает решения и повторяет действия

# Что внутри
- **Сравнение** - как сравнивать данные
- **Условия** - if / elif / else - выбор пути
- **Структура сопоставления** - match case (Python 3.10+)
- **Циклы** - while / for - повторение действий
- **Управление циклами** - break / continue / pass - контроль над повторениями
- **Генераторы списков** - короткий способ создавать списки
- **Обработка ошибок** - try / except - защита от падения

# Для чего это нужно
Без этого блока программа - просто набор данных. С ним же - программа становится живой: она реагирует, выбирает, адаптируется

# Что такое if / elif / else
Это **условный оператор**, который выполняет разные блоки кода в зависимости от условия

# Когда использовать:
- Когда нужно проверить несколько **сложных условий** (сравнения, логика and / or)
- Когда условие зависит от **вычислений**
- Когда веток не слишком много (до 3-4), иначе код становится громоздким

# Синтаксис
if условие1:
    код, если условие1 истинно
elif условие2:
    код, если условие1 ложно, а условие2 истинно
else:
    код, если все условия ложны

# Что такое match case
Это **структурное сопоставление**. Оно сравнивает **одно значение** с несколькими шаблонами и выполеяет код для первого совпавшего

# Когда использовать:
- Когда нужно сравнить **одну переменную** с множеством конкретных значений
- Когда нужно **разобрать структуру** (список, кортеж, словарь, объект класса)
- Когда цепочка if/elif становится слишком длинной и трудночитаемой

# Синтаксис
match значение:
    case шаблон1:
        код, если значение совпало с шаблоном1
    case шаблон2
        код, если значение совпало с шаблоном2
    case _:
        код, если ни один шаблон не подошел

# Почему match case лучше if в некоторых случаях:
- Код становится **короче** и **читабельнее**
- Быстрее писать, когда много вариантов


# Цикл while

Цикл while выполняет блок кода **пока условие истинно**

# Синтаксис
while условие:
    код, который повторяется

# Когда использовать
- Когда заранее неизестно, сколько раз нужно повторить действие
- Когда нужно повторять, пока не произойдет событие
- Когда нужно создать бесконечный цикл

# Опасность
Если условие никогда не станет ложным, цикл будет бесконечным и программа зависнет


# Цикл for

Цикл for используется для перебора элементов коллекции

# Синтаксис
for элемент in коллекция:
    тело цикла

# Основные возможности
- range() - генерация последовательностей
- enumerate() - получение индекса и элемента
- zip() - параллельный перебор нескольких коллекций
- reversed() - обратный порядок
- sorted() - сортировка без изменения оригинала

# Управление циклом
- break - выход из цикла
- continue - переход к следующей итерации
- else - выполняется, если цикл завершился без break

# Когда можно использовать
- Перебор всех элементов коллекции
- Выполнение действия N раз
- Работа с данными

# Управление циклами: break, continue, pass, else

Эти инструкции работают одинаково для for и while

# break
- **Что делает:** немедленно **прерывает** выполнение цикла, выходит из него
- **Где использовать:** когда нашел нужный элемент / достиг цели / произошла ошибка

# continue 
- **Что делает:** **пропускает** текущую итерацию и переходит к следующей
- **Где использовать:** когда элемент не подходит под условие и его нужно игнорировать

# pass
- **Что делает:** ничего не делает, просто заглушка для синтаксиса
- **Где использовать:** когда нужно временно оставить блок кода пустым

# else
- **Что делает:** блок else выполняется, если цикл завершился **естественным путем**
- **Где использовать:** для проверки, был ли найдет элемент, без использования флагов

# Синтаксис
